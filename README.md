# Ghulam Qadir — Premium Portfolio

React + Vite + Framer Motion portfolio.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Customize before publishing

Open `src/main.jsx` and update:
- Email address (`your.email@example.com`)
- GitHub URL
- LinkedIn URL
- Project links
- Project descriptions
- Skills
- Services

## Deploy

### Vercel
Import the GitHub repository into Vercel. The default Vite build settings work.

### GitHub Pages
You can also publish the `dist` folder through GitHub Pages after running `npm run build`.
For a Vite project on a GitHub Pages project site, set the correct `base` in `vite.config.js` if the repository is not served from the domain root.

## Notes

The project uses remote Google Fonts. If you want a fully self-contained deployment, replace them with locally hosted fonts.
